# Naver Focus 9.1.1.2026

네이버의 뉴스, 댓글, 메인 화면을 사용자가 원하는 방식으로 정리하는 Chrome Manifest V3 확장 프로그램의 첫 번째 작업본입니다.

## 현재 들어간 기능

- 뉴스 키워드 즉시 필터
  - 뉴스 목록의 제목, 요약, 카드 텍스트를 먼저 검사합니다.
- 기사 본문 심층 필터
  - 화면에 가까워진 기사만 조회합니다.
  - 기사 본문 분석 결과를 로컬 캐시에 저장해 반복 요청을 줄입니다.
- 기사 직접 진입 가드
  - 기사 본문에서 차단 키워드가 발견되면 `뒤로 가기 / 이번만 보기` 화면을 표시합니다.
- 네이버 댓글 사용자 우클릭 차단
  - `댓글모음`, 닉네임, 작성자 영역에서 우클릭합니다.
  - `profileUserId -> targetMark/_user_id_no_* -> idNo -> userName` 순서로 사용할 수 있는 식별값을 선택합니다.
- 댓글 키워드 차단
  - 뉴스와 같은 차단 키워드가 댓글 본문에 포함되면 해당 댓글 전체를 숨깁니다.
- 댓글 작성자 호버 안내
  - 우클릭 차단 기능을 작은 툴팁으로 안내합니다.
- 페이지 요소 직접 숨김
  - 확장 팝업의 `이 페이지에서 숨길 영역 선택`을 사용할 수 있습니다.
  - Chrome 우클릭 메뉴의 `Naver Focus: 이 영역 숨기기`도 사용할 수 있습니다.
  - Naver CSS-module 해시 전체가 아니라 안정적인 prefix, data 속성, aria 속성을 우선해 선택자를 만듭니다.
- 잡다링크 숨기기
  - 뉴스의 알고리즘·구독·프리미엄·서비스 안내 배너를 내장 규칙으로 숨기고 토글을 끄면 복원합니다.
- 네이버 미니멀 홈
  - 네이버 원본 로고·검색 DOM·광고 영역을 유지하고 작은 `NaverRefresher` 제어 바만 덧붙입니다.
  - 원본 검색창의 제출만 Google 검색으로 연결하고 Google 결과 링크의 출처는 그대로 유지합니다.
  - 로그인 상태에서는 원본 DOM에서 읽은 nickname으로 현재 화면에만 인사를 표시합니다.
- 설정 화면
  - 차단 키워드, 차단 사용자, 숨긴 영역, 최근 필터링 기록을 관리합니다.
  - 설정 JSON 내보내기/가져오기를 지원합니다.

## 설치

1. 이 폴더를 원하는 위치에 둡니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 우측 상단 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
5. 이 폴더(`naver-focus-extension`)를 선택합니다.

## 기본 사용법

### 뉴스 키워드

확장 아이콘을 눌러 팝업에서 키워드를 추가합니다. 제목/요약에 키워드가 있으면 즉시 숨기고, `기사 본문까지 분석`이 켜져 있으면 화면 근처 기사만 본문을 조회해 추가로 판정합니다.

### 댓글 사용자 차단

네이버 뉴스 댓글의 닉네임 또는 `댓글모음` 영역에 마우스를 올리면 안내가 표시됩니다. 해당 작성자 영역에서 우클릭하면 로컬 차단 목록에 추가되고 같은 식별값의 댓글이 숨겨집니다. 같은 영역을 다시 우클릭하면 차단이 해제됩니다.

차단 키워드는 댓글 본문에도 적용됩니다. 사용자 차단과 키워드 차단은 별도 사유로 관리되므로 한 사유가 해제되어도 다른 사유가 남아 있으면 댓글은 계속 숨겨집니다.

### 페이지 요소 숨김

팝업의 `이 페이지에서 숨길 영역 선택`을 눌러 네이버 페이지에서 제거할 영역을 클릭합니다. 또는 먼저 대상 영역을 우클릭한 다음 Chrome 메뉴의 `Naver Focus: 이 영역 숨기기`를 선택합니다.

### 미니멀 홈

팝업 또는 상세 설정에서 `미니멀 홈`을 켭니다. 네이버 메인에서 원본 로고·검색창을 유지하고 검색 제출을 Google로 연결합니다. 화면 오른쪽 위 `기본 화면` 버튼으로 즉시 끌 수 있습니다.

## 저장되는 데이터

모든 사용자 설정은 `chrome.storage.local`에 저장합니다.

- 차단 키워드
- 댓글 사용자 식별값과 표시명
- 숨긴 CSS 선택자
- 기사 본문 분석 캐시
- 최근 필터링 기록

외부 서버나 별도 분석 서버로 설정을 전송하는 코드는 포함하지 않았습니다.

## 현재 작업본에서 의도적으로 하지 않은 것

- 자동 테스트 파일 생성
- 자동 테스트 실행
- 테스트용 fixture 생성
- 빌드 도구 / npm 의존성 추가
- AI/ONNX 기반 댓글 내용 판정
- 네이버 계정의 실제 차단 API 조작

댓글 차단은 네이버 서버 계정 설정을 변경하지 않고 이 확장 내부에서 로컬로 숨기는 방식입니다.

## 주의

네이버는 DOM 구조와 CSS-module 이름을 변경할 수 있습니다. 이 작업본은 2026-09-27에 제공된 실제 네이버 DOM 예시를 기준으로 복수의 selector fallback을 넣은 초기 뼈대입니다. 이후 실제 사용 중 깨지는 지점을 좁혀 Codex로 보강하는 흐름을 전제로 합니다.

테스트는 요청에 따라 생성하거나 실행하지 않았습니다.
